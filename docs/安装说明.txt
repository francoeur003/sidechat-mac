侧语 SideChat 0.2.0 — Mac Apple Silicon

系统：macOS 14 或更新版本，Apple Silicon（M1 及更新芯片）。
已内置运行环境，无需 Python、终端或本地大模型。

1. 把 SideChat.app 拖入 Applications（应用程序）。
2. 首次只填 Jev API Key 和 DeepSeek API Key，点击“同意并连接”。
   应用会先测试两个接口，连接成功后保存到本机钥匙串。
   Jev 负责意图和排序，DeepSeek 负责生成回复，模型与地址已内置。
3. 按 macOS 提示允许屏幕录制，然后打开一个微信对话。
   浅色微信聊天区域会自动定位，窗口缩放后重新检测，无需默认手动框选。
   不能确定范围时停止分析，点击“调整范围”手动修正。
4. 看到回复后可复制；“填入”需要辅助功能权限，不会点击发送。

升级 0.1.0 后需重新同意连接，因为新的流程会使用两个服务商。
测试连接和分析会消耗各自 API 账户额度。聊天文字、上下文和候选回复会发往
Jev 与 DeepSeek；截图只在本机用于 OCR。Key 不随应用分发。

本社区版本尚无 Apple Developer ID 签名与公证。
首次运行被阻止时，请确认来源和 SHA256 校验值，再自行到系统设置 → 隐私与安全性允许打开。
无需关闭全局 Gatekeeper。

自动检测只支持已验证的浅色微信桌面布局。无法确定、窗口过小或深色布局时不会猜测范围。
图片、表情与语音暂不支持。模型判断不是保证正确的“最优解”。Intel 版本未验收。

本地设置：~/Library/Application Support/SideChat/
运行日志：~/Library/Logs/SideChat.log
源代码：https://github.com/francoeur003/sidechat-mac
